## 主要修复

- 修复天凤和牌事件缺少 `hora`、多家荣和与终局边界不完整的问题，使 FlyAPI 可以正确回放跨小局状态。
- 修复吃碰后的弃牌被错误标记为摸切、碰牌物理牌副本解码错误，以及红五附近可能出现的手牌状态损坏。
- 修复 Chromium WebSocket 重连时重复或无关连接被误判为游戏连接的问题；断线后立即停止向 FlyA 提交残缺事件，并从下一次完整 `start_kyoku` 自动恢复新会话。
- 修复 FlyA `state_replay_invalid` 持续重试、下一小局仍处于请求失败状态的问题。
- 本家立直成立后直接执行自动摸切，仅同步协议状态，不再请求 FlyA、OT3 或本地模型。
- 修复启用 mihomo TUN 时无法在“内置窗口 / 外部代理”之间保存切换的问题：切入内置窗口会停止 TUN，切回外部代理会按原启用偏好自动恢复。
- 移除独立 TUN 权限助手及容易误报的 UAC 等待链路。Windows 主程序现在以管理员权限启动并直接管理 mihomo。

## 稳定性与诊断

- FlyA 请求日志增加安全的序列范围、状态摘要、会话 ID、错误代码和尾部事件诊断，不记录 API Key。
- 改进天凤重连连接选取和 CDP `requestId` 跟踪，减少重开游戏后的事件丢失与错误接管。
- 保留本地模型回退；FlyA 对局历史不完整时不会继续发送必然失败的请求。
